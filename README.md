# Number Guessing Game

A simple command-line game where you try to guess a randomly chosen
number between 1 and 10. The game tells you if your guess is too high
or too low, and counts how many guesses it took you to win.

## Requirements

Just Python 3 -- no external packages needed.

## Usage

```bash
python3 Guess_Game.py
```

Example:

```
Guess a number: 5
Higher number please!
Guess a number: 8
Lower number please!
Guess a number: 7
Congratulations! You guessed the number 7 in 3 guesses.
```
